# asdf-educates

[asdf](https://asdf-vm.com) plugin for the [Educates](https://docs.educates.dev) CLI.

```sh
asdf plugin add educates <this-repo-url>
asdf install educates latest
asdf set educates 3.8.0        # asdf >= 0.16 (older: asdf global educates 3.8.0)
educates version
```

Supports linux/darwin on amd64/arm64. Downloads are verified against the release `checksums.txt`.
